# Debt Ledger App (دفتر الذمم)

A web application that helps small merchants track debt records for their customers — who owes what, how much, and when it's due.

## 🚀 Features

- Add, edit, and delete customer debt records
- Track amounts owed and payment status
- Data persistence (localStorage, migrating to a PHP + MySQL backend)
- Clean, responsive UI built with Tailwind CSS

## 🛠️ Tech Stacks

- **Frontend:** React, Vite, Tailwind CSS
- **Backend (in progress):** PHP, MySQL (via XAMPP)
- **Deployment:** Vercel

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/AminaDevp/debt-tracker.git
cd debt-tracker

# Install dependencies
npm install

# Run the development server
npm run dev
```

The app will be available at `http://localhost:5173`.
